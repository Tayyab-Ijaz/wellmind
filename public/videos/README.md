# WellMind Hero Video

Place the final video here as `hero.mp4`.

The hero uses the native HTML5 `<video>` element with `preload="auto"`, `autoplay`, `muted`, `loop`, and `playsInline`. The video is displayed at the full hero size with `object-fit: cover` and no blur/filter/canvas processing.

For the sharpest result, use a 4K (3840×2160) master when possible.
